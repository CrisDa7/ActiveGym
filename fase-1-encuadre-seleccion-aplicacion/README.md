# Fase 1: Encuadre del componente práctico y selección de la aplicación objetivo

**Semana 1 - del 28 de septiembre al 02 de octubre de 2026**

## Objetivo
Organizar el componente práctico experimental y seleccionar la aplicación objetivo (ActiveGym) para el análisis de seguridad.

## Sesión 1: Organización y exploración de candidatos
**Jueves 01 de octubre, 09h30 a 11h30**

### Actividad 1: Socialización de la organización del componente APE (25 minutos)
- Presentación de la organización del componente práctico experimental
- Revisión de guías, fases, entregables, rúbricas y cronograma

### Actividad 2: Diagnóstico práctico inicial (20 minutos)
- Cuestionario sobre conceptos fundamentales de seguridad:
  - Tríada CIA (Confidencialidad, Integridad, Disponibilidad)
  - Vulnerabilidades
  - Superficies de exposición

### Actividad 3: Exploración de candidatos a aplicación objetivo (45 minutos)
- Revisión de proyectos anteriores para cumplir requisitos mínimos:
  - Código fuente disponible
  - Ejecución local posible
  - Sistema de autenticación
  - Base de datos
- Verificación de instalación de entornos controlados (DVWA u OWASP Juice Shop)

### Actividad 4: Registro del proyecto
- Documentación de la aplicación seleccionada
- Creación del repositorio en GitHub

## Sesión 2: Puesta en marcha e inventario inicial
**Viernes 02 de octubre, 07h30 a 09h30**

### Actividad 1: Confirmación de criterios y alcance
- Validación de que ActiveGym cumple con los requisitos mínimos
- Definición del alcance del análisis de seguridad

### Actividad 2: Puesta en marcha del entorno
- Configuración del entorno de desarrollo
- Ejecución local de la aplicación
- Verificación de funcionamiento correcto

### Actividad 3: Inventario inicial de la superficie de ataque
- Identificación de puntos de entrada:
  - Endpoints de la API
  - Formularios de autenticación
  - Páginas públicas
  - Interfaces de administración

### Actividad 4: Cierre y consolidación
- Documentación de hallazgos iniciales
- Preparación de evidencias

## Entregables
- [ ] Registro del proyecto en GitHub
- [ ] Ficha del proyecto (FICHA_PROYECTO.md)
